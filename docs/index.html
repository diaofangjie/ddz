迭代路线图 止血 → 安全 → 可测 → 重构 → 扩容 → 体验

0

止血 · 让项目可回滚、不可作弊

建立 git 与基线 tag、物理备份、身份由服务端签发、视图裁剪初版、补阶段校验。同时处理云服务器到期风险（备份 + 设置提醒）。

验收：git log 有 baseline；篡改身份的脚本失效
1

可测试化 · 建立安全网

引入 Vitest，抽出 domain/ 纯函数层（行为零变化），补齐牌型、比较、计分、发牌、状态机共 70+ 条用例。

门槛：domain/ ≥ 200 用例全绿，行覆盖 ≥ 90%
2

架构重构 · 绞杀者模式

统一广播出口、统一调度器、状态机显式化、座位模型、拆分 index.js 与 GameScreen.js。每个子任务单独提交、单独可回滚。

验收：测试全绿；index.js < 100 行；无重复阶段分支
3

在线能力 · 用户的核心诉求

HTTPS + 域名、同域相对路径、座位 + 观战席（总容量 10）、观战与轮换、SQLite 持久化、重连强化、安全加固。并决定试用到期后的主机方案。

验收：微信内可打开；满员后进观战席且看不到任何手牌；重启后房间可恢复
4

体验与运营

战绩体系、复盘回放、房间管理后台、音效动效、观战增强、voteExtend 需求池补齐。
