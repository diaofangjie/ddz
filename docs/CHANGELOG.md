# 变更日志

本项目所有值得记录的变更都写在这里。
格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

分类含义：
- `新增` — 新功能
- `变更` — 对已有功能的调整
- `修复` — 缺陷修复
- `移除` — 删除的功能
- `安全` — 安全相关的修复或加固
- `文档` — 仅文档变更

写"用户能感知的变化"，不要写 `fix: update code` 这类无信息量的描述。

## 历史记录说明

本项目在本次文档化之前**没有版本控制，也没有变更日志**。
现有功能（详见 `README.md` 的功能清单）以 `v1.0.0-baseline` 作为**首次可追溯的基线版本**：

- 3 人 / 4 人斗地主
- 创建 / 加入房间、房间号邀请
- 癞子玩法（`normal` / `tiandi`）
- 加倍 / 超级加倍、封顶倍数
- 弃牌阶段（4 人局）
- 2v2 队伍模式（红蓝）
- 局数选择（4 / 8 / 16）
- 文字聊天
- 断线重连 + 离线 AI 托管
- 记牌器
- PWA、Capacitor Android/iOS 打包

## 版本号约定（从 v1.0.0-baseline 之后开始执行）

| 位 | 含义 | 示例 |
|----|------|------|
| 主版本 | 破坏性变更：协议不兼容、数据结构定型改变 | `v1.3.0 → v2.0.0`（`proto 1 → 2`） |
| 次版本 | 新增功能，向后兼容 | `v1.1.0` 新增观战席 |
| 修订号 | 缺陷修复、内部重构 | `v1.0.1` 修复计分不守恒 |

**打 tag 的时机**：合入 `main` 并完成线上验证后。tag 信息里写明本次部署的验证结论。
