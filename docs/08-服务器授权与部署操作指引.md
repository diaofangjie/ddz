# 08 - 服务器授权与部署操作指引

> 面向非运维人员的手把手教程。
> 目标：让我拿到服务器登录权限 → 我自动完成部署。
> 编写时间：2026-09-16

---

## 0. 为什么需要你做这一步

我这边已经把部署工具写好了（`scripts/aliyun.py`），能自动完成备份、上传、替换、重启、验收全部 8 个步骤。

但有一个环节我无论如何绕不过去：**服务器只允许密钥登录**。

实测结论：

| 检查项 | 结果 |
|--------|------|
| `8.137.195.155:22` | 开放，`OpenSSH_8.9p1 Ubuntu-3ubuntu0.17` |
| 服务器接受的认证方式 | **仅 `publickey`**（密码登录已在服务端关闭） |
| 本机是否有私钥 | **没有**，`~/.ssh` 里只有一个 0 字节的空配置 |
| 全盘搜索 `.pem/.ppk/id_rsa` | 无结果 |
| 本机是否有阿里云 AccessKey | 没有，无法走「云助手 API」远程执行 |

密钥是"证明你是这台机器主人"的唯一凭据，只能由你从阿里云账号侧授予。**这一步别人替不了。**

所以流程是：**你花 1 分钟授权 → 我花几分钟自动部署完**。

## 1. 推荐路线：云助手（免重启、免密码、免登录服务器）

### 为什么推荐

- 不需要知道服务器密码
- 不需要重启实例（不会中断正在打牌的人）
- 不需要装任何软件
- 全程在浏览器里点，约 1 分钟

### 操作步骤

**第 1 步 · 登录控制台**

浏览器打开 `https://ecs.console.aliyun.com/`，用你的阿里云账号登录。

**第 2 步 · 进入云助手页面**

左侧菜单栏依次点：

```
运维与监控  →  发送命令/文件（云助手）
```

> 进去以后先看页面**左上角的地域**选择器。必须选成你服务器所在地域，
> 否则下面的实例列表里找不到这台机器。不确定选哪个，就把地域逐个试，
> 哪个能在列表里看到 `8.137.195.155` 就是对的。

**第 3 步 · 创建命令**

点页面**右上角的「创建/执行命令」**，右侧会滑出一个配置面板。

**第 4 步 · 填配置并粘贴命令**

按下面填：

| 配置项 | 填什么 |
|--------|--------|
| 命令来源 | 输入命令内容 |
| 命令名称 | `add-deploy-key`（随便起，仅用于记录） |
| 执行计划 | **立即执行** |
| 命令类型 | **Shell** |
| 执行用户 | `root`（默认，不用改） |
| 超时时间 | `60`（默认） |

然后把下面这段整段复制到「命令内容」框里（粘贴前先清空）：

```bash
mkdir -p /root/.ssh
chmod 700 /root/.ssh
touch /root/.ssh/authorized_keys
grep -q 'ddz-deploy-2026' /root/.ssh/authorized_keys 2>/dev/null || echo 'ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQC4tVHIho5UtIlQIOibf4pCtywMA8iaH/nUx0edmeEyGV4j+88ojSvdCVUe176goii3zFuYfzKNURBClFmFQApiIMswcRK0RYPg7WkIw0bvAQbvsmyJn9VlnfEkrs3pUQUibdCFTKbQe9x0KYnVBrKmJLHFghXt7PirXBr1aSkaUgUOgO2YqfvWofOjStHtWYBhOiZIbnSbtZhs2a5TCDdDd/LiBQC8EJCohI8T6VLxG6cZyJ7PjOXxjBelK2bn73nzG+lKaCOojARBuMuRdCAjPcVBHU0nkawudPDtGlMhRJyB2xt3dcEdt7AzRiTE+q2W6+F9eUhm+t7O9Svcj1Jv ddz-deploy-2026' >> /root/.ssh/authorized_keys
chmod 600 /root/.ssh/authorized_keys

```

> 这段脚本只做一件事：把一把公钥追加进 `/root/.ssh/authorized_keys`。
> 它**不会**改动游戏代码、不会重启任何服务、不会动数据库。
> `grep -q ... || echo ...` 是幂等保护：重复执行也不会写重复行。

**第 5 步 · 选择实例并执行**

在面板下方「选择实例」区域，勾选 IP 为 `8.137.195.155` 的那台实例，
然后点面板底部的**「执行」**按钮。

> ⚠️ 如果这台实例在列表里是**灰色、勾不上**，说明该实例没装云助手 Agent，
> 请改走第 2 节的备选路线。

**第 6 步 · 确认成功**

等约 5 秒，在「执行结果」里看输出。看到这一行就是成功了：

```
===BIND_OK===
```

然后回来跟我说一声，剩下的我全自动跑。

## 2. 备选路线：密钥对（可能需要重启实例）

云助手不可用时走这条。

**第 1 步 · 创建密钥对**

左侧菜单：

```
网络与安全  →  密钥对  →  右上角「创建密钥对」
```

在弹出的面板里填：

| 配置项 | 填什么 |
|--------|--------|
| 密钥对名称 | `ddz-deploy` |
| 创建类型 | **导入已有密钥对** |
| 公钥内容 | 粘贴下面这一整行 |

```text
ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQC4tVHIho5UtIlQIOibf4pCtywMA8iaH/nUx0edmeEyGV4j+88ojSvdCVUe176goii3zFuYfzKNURBClFmFQApiIMswcRK0RYPg7WkIw0bvAQbvsmyJn9VlnfEkrs3pUQUibdCFTKbQe9x0KYnVBrKmJLHFghXt7PirXBr1aSkaUgUOgO2YqfvWofOjStHtWYBhOiZIbnSbtZhs2a5TCDdDd/LiBQC8EJCohI8T6VLxG6cZyJ7PjOXxjBelK2bn73nzG+lKaCOojARBuMuRdCAjPcVBHU0nkawudPDtGlMhRJyB2xt3dcEdt7AzRiTE+q2W6+F9eUhm+t7O9Svcj1Jv ddz-deploy-2026
```

> 🔴 **创建类型一定要选「导入已有密钥对」**。
> 如果选了「自动新建」，私钥只在阿里云那边生成、只让你下载一次，
> 我这边就永远拿不到，等于白做。

**第 2 步 · 绑定到实例**

回到「密钥对」列表，找到刚建的 `ddz-deploy`，在它右侧的**「操作」列**点：

```
绑定密钥对  →  在弹窗里把 8.137.195.155 那台移到右侧「已选择」  →  确定
```

**第 3 步 · 重启（可能需要）**

阿里云官方文档写：**绑定/换绑密钥对需要重启实例才能生效**。
但部分资料也表示实例运行中绑定时可即时生效。

**所以顺序是：绑定完先别重启，直接回来跟我说一声**，
我立刻试连一次 —— 通了就继续，不通我再叫你重启，不浪费你的时间。

> ⚠️ 重启约 30 秒～1 分钟，会中断正在进行的对局（游戏没有做持久化）。
> 请挑没人在玩的时候做。

**其他影响（提前告知）**

- 一台实例最多绑定一个密钥对，绑定新的会**替换**旧的。本机没找到任何旧密钥，
  所以大概率没有别人在用旧的那把。
- 实例原本若是密码登录，绑定密钥对后原密码自动失效（本次本来就是密钥登录，无影响）。

## 3. 授权之后我会做什么（你不需要管）

你说一声「好了」，我执行：

```bash
cd D:/dfj/dfj/ddz
python scripts/aliyun.py check     # 只读盘点，摸清线上真实目录结构
python scripts/aliyun.py deploy    # 正式部署
```

`deploy` 的 8 个步骤：

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 前置检查 | 确认项目目录结构正确、pm2 进程存在 |
| 2 | 备份 | `server/src.bak.<时间戳>` + `client/build.bak.<时间戳>` |
| 3 | 上传 | SFTP 上传发布包，**比对字节数**确认完整 |
| 4 | 覆盖 | 只替换 `server/src` 与 `client/build`，不动 nginx 和依赖 |
| 5 | 校验 | 检查 `projectGame`/`pickBomb`/`sessionToken` 三处特征，**计数为 0 立即中止** |
| 6 | 依赖 | 只有 `package.json` 变了才 `npm install` |
| 7 | 重启 | `pm2 restart ddz-server` |
| 8 | 验收 | 轮询 `/health` 直到返回 `{"status":"ok"}`，并检查首页 HTTP 状态码 |

出任何问题都能 30 秒回滚：

```bash
python scripts/aliyun.py rollback <备份时间戳>
```

## 4. 常见问题

**Q：找不到「运维与监控」菜单？**

不同版本控制台分层略有差异，备用入口：进入「实例」列表 → 点进 `8.137.195.155`
的实例详情页 → 顶部「全部操作」→ 搜索框输入「发送命令」。

**Q：云助手页面里看不到我的实例？**

九成是地域选错了。逐个切换左上角地域找找。

**Q：执行成功但你还是连不上服务器？**

把执行输出截图发我，我帮你判断。常见原因是 `/root/.ssh` 权限不对，
脚本里已经处理了（700 / 600），一般是别的问题。

**Q：安全上有什么风险？**

- 加了这把公钥后，**只有持有对应私钥的人**（也就是本机
  `C:\Users\DFJ\.ssh\ddz_aliyun`）能登录服务器的 root。
- 私钥只存在你本机，不会外传、不会上传到任何地方。
- 如果你想撤销授权，随时可以在服务器上删掉 `authorized_keys` 里的那一行，
  或者在阿里云控制台解绑密钥对。

**Q：我能自己做完部署，不用你吗？**

可以，见 `docs/07-发布部署运行手册.md`，里面有完整的命令行步骤和回滚方法。
